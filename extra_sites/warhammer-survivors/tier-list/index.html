Warhammer Survivors Tier List

October demo character comparison: documented starting tools and playstyle notes, without unsupported strength tiers.

Last updated 2026-10-26 · October demo

🚧 Demo-era comparison: The table summarizes official descriptions and limited preview observations. It is not a measured strength ranking.

The available previews do not provide repeated, comparable runs across all six champions. Clear speed, survival rate, map, upgrades and unlock state have not been measured under a shared method, so an S-to-C ranking would overstate the evidence.

What a future ranking needs

Compare repeated runs with the same mode, stage, unlock state and build rules, and record completion time, deaths/failures and upgrade choices. Until those observations exist, these are playstyle notes only; no S/A/B/C tier is assigned.
