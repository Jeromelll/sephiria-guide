Sephiria Hard Mode / Root’s Retreat unlock

For sephiria roots retreat / hard mode / how to unlock hard mode.

Players search sephiria roots retreat, sephiria hard mode, and how to unlock hard mode because Hard Mode is gated and still listed under the Root’s Retreat achievement names.

Current unlock (post Update 0.7.55)

  1. Finish Chapter 2 (story progress, not just a random boss).
  2. Return to Bunnyville and talk to the Destiny tree.
  3. Open dialogue topics and select Hard Mode.

After that conversation, Hard Mode / Root’s Retreat becomes available for later runs. You do not need to buy a paid Destiny node on the normal path.

Root’s Retreat stage names

Steam achievements treat Root’s Retreat as Hard Mode stage clears, not a separate village:

  • Root’s Retreat — clear Hard Mode Stage 1
  • Root’s Retreat 15 — clear Stage 15
  • Root’s Retreat 30 — clear Stage 30
Version trap: Steam “Basic Guide” and some EA discussions still say Hard Mode is a free node at the bottom of Destiny Inscription. That was true early on; TEAM HORAY moved the regular unlock to the tree dialogue in 0.7.55. If a guide only sends you to Destiny Inscription, treat it as legacy.

Legacy / failsafe notes

  • Very old saves may still see a Destiny Inscription fallback (Steam discussion era / later failsafe patches).
  • If the tree says Hard Mode unlocked but you cannot find the entrance UI, check Sapphire/Destiny menus and restart the hub—community threads report UI lag after unlock.

What Hard Mode is for

Hard Mode adds tougher dungeon modifiers (community 1.0 writeups list many “elements” / challenge toggles) and is the place people take proven builds after clearing the story route. Talent budget also expands once Hard Mode access is online—exact talent totals can change by patch, so verify in-client.
