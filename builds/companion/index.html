Companion build

For sephiria companion build / summoner searches.

sephiria companion build searches want a summoner route: stack Companion-tagged Artifacts, keep them leveled, and let pets soak aggro while you finish elites/bosses.

Core idea

  • Prioritize Companion family items early (contracts, moles, jellyfish, cushions, etc.). Community clear videos treat “get all companions online” as the first-floor job.
  • Ballista / mine-crossbow evolutions play like extra companions once mines become seeking drones.
  • Put Tablets and buffs on companions, not on random side DPS tags.
  • Companions are expensive to max—Dimensional Pocket / Willpower lines that carry items between runs make the build much smoother.

Run habits

  • Accept Storm Cloud or light fire as secondary only if it supports Ballista/mines—do not dilute five tags.
  • In co-op, companions keep drawing aggro so human players can focus mechanics.
  • After bosses, rebuild adjacency so Companion pieces stay bonded.
Theme-level consensus also appears in 9Puz / SlashSkill “commit to one combo family” advice. Exact item IDs shift with patches—use the Journal and this page’s video sources for current names.
