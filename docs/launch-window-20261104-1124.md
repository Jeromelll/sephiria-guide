- 每条事实带来源和核验日期；**重验失败就保留旧日期，不假装重验过**。sortitoutsi / fmscout 对纯 curl 返回 403/000（Cloudflare 拦截），重验需登录态浏览器或 AgentKey 抓取通道。
- 免费期措辞：只在确认窗口真正结束后才改成「已结束」（见下）。
- 战术页没有本机实测就不加「best tactic」或阵型参数；球员资料沿用已上线来源，不生成虚构属性。

流程（每天一轮）：

1. 抓源：sortitoutsi FM27 内容区与 graphics 区、fmscout FM27 区（curl 被拦 → 用登录态浏览器，或 AgentKey 抓取类工具，勿裸爬重试超过 2 次）。

4. build + 检查门 + push（自动部署）。留痕：每天一行到本文件底部日志。

降级条件：源站结构变化或连续两天无法取数 → 停自动节奏，改成人工隔天核验，并在本文件记录。
